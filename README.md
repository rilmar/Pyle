# Pyle
An ingress for Voron-based toolchangers replacing the rear exhaust port.

`Pyle` - Greek for gate - continues the trend of providing a greek name for tool changing projects and I also use greek mythological names for labeling my projects.

This is a system that replaces the rear top exhaust and provides a foam-lined ingress slot for cables and routes for ptfe tubes aiming to assist the building of hotend swapping tool changing systems. The design is meant to be generic and support a variety of systems. Additionally this repository contains enclosures for common tool distribution boards like the Hydra to increase tool, fan, and thermistor ports. As more boards become available they will be added.

## Supported hardware
[Pulsar 3d's Hydra](https://github.com/Pulsar3D-Official/Hydra)


## BOM
Most parts used are common voron parts including M3 screws and voron standard heatsets. VHB tape is used to mount the board enclosures on the rear panel and 3mm x 5mm foam tape is used around the wire inlet to provide some barrier between inside and outside.

A better BOM will be available as the project matures.
